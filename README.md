# Dentalam

Landing page de Dentalam, clínica de especialidades dentales en Ciudad Juárez.

Sitio estático (HTML, CSS y JS sin dependencias ni compilación). Para verlo, abre `index.html` en el navegador o publícalo en cualquier hosting estático (GitHub Pages, Netlify, Vercel).

## Estructura

- `index.html`: contenido de la página
- `css/styles.css`: estilos (colores en variables al inicio del archivo)
- `js/main.js`: animación al hacer scroll y enlace de WhatsApp de la promoción
- `assets/`: imágenes

## Cambiar la promoción

Edita el bloque marcado como `Promoción` en `index.html`: imagen, etiqueta, título, descripción, nota y texto del botón. El mensaje de WhatsApp del botón se arma solo con el título. Para ocultar la promoción, borra o comenta esa `<section>`.
